RA Portfolio Website
====================

Files:
- index.html: page content and sections
- style.css: colors, layout and responsive design
- script.js: animated particles, click ripple, mobile menu, Discord username copy

Publish with GitHub Pages:
1. Upload these files to the root of your GitHub repository (not the ZIP).
2. In Settings > Pages, select "Deploy from a branch".
3. Select branch "main" and folder "/ (root)", then Save.
4. Wait for the Pages deployment to finish.
